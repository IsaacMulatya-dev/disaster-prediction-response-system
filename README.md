# AI-Powered Disaster Prediction and Response System

## Overview
This system uses AI to predict and respond to natural disasters in real time. Built manually using React, Vite, Tailwind CSS and Supabase, it features a responsive UI and integrates live data feeds for proactive alerts.

## Technologies Used
- React + TypeScript
- Vite
- Tailwind CSS
- Supabase
- shadcn-ui

## Setup Instructions
```bash
git clone https://github.com/IsaacMulatya-dev/ai-guardian-alert.git
cd "AI-POWERED DISASTER PREDICTION AND RESPONSE SYSTEM"
npm install
npm run dev
